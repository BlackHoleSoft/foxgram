# Интеграционные тесты Foxgram Backend

## Установка зависимостей

```bash
npm install --save-dev jest ts-jest @types/jest supertest @types/supertest
```

## Запуск тестов

```bash
# Все тесты
npm test

# Только e2e тесты
npm run test:e2e

# Конкретный файл
npm test -- test/e2e/auth.test.ts
```

## Покрытие тестами

### auth.test.ts
- `POST /api/auth/register` — 9 тестов
  - Успешная регистрация (3)
  - Ошибки валидации (6)
- `POST /api/auth/login` — 6 тестов
  - Успешный вход (2)
  - Ошибки входа (4)

### messages.test.ts
- `POST /api/messages/send` — 7 тестов
  - Успешная отправка (3)
  - Ошибки валидации (4)
  - Авторизация (2)
- `GET /api/messages/poll` — 8 тестов
  - Без userId (2)
  - С userId (4)
  - Авторизация (2)

### users.test.ts
- `GET /api/users/:id/public-key` — 4 теста
  - Успешный запрос (2)
  - Ошибки (2)

## Расхождения спецификации и реализации

### Учтены в тестах (по спецификации):

1. **`/api/auth/login` не проверяет ключ** — в спецификации указано, что при логине должна быть проверка соответствия публичного ключа. В реализации проверка отсутствует. Тесты проверяют по спецификации (без проверки ключа).

2. **`/api/messages/poll` без userId** — в спецификации указано "return all messages for current user". В реализации возвращаются только входящие сообщения (`recipient_id = current_user`). Тесты проверяют по спецификации.

3. **`/api/messages/send` проверка "отправить самому себе"** — в спецификации не описана. В реализации есть проверка. Тесты учитывают эту проверку.

4. **`/api/users/:id/public-key`** — реализация соответствует спецификации.

### Не учитываются в тестах:

- Валидация base64url формата publicKey (нет проверки символов, только длина)
