# CL006 — cli: Chat screen

## Модуль
`packages/cli`

## Описание
Реализовать экран чата: отображение истории сообщений, ввод и отправка, polling новых сообщений.

## Контекст
- Документация: `docs/cli.md` (секция Chat)
- Зависит от: CL001-CL005

## Задачи

### 6.1 Создать `src/screens/chat.ts`

Терминальный экран:
```
┌─────────────────────────────────┐
│  ← Back           bob           │
├─────────────────────────────────┤
│                                 │
│  [12:30] alice: Hello!          │
│  [12:31] bob: Hi there!         │
│  [12:32] alice: How are you?    │
│                                 │
│  [12:33] bob: Fine, thanks!     │
│                                 │
│                                 │
├─────────────────────────────────┤
│  [________________________________] │
│                            [Send]│
└─────────────────────────────────┘
```

```typescript
// MessageItem — отдельное сообщение

// ChatInput — поле ввода
// - Enter — отправить
// - Escape — назад
```

### 6.3 Логика сообщений

```typescript
// Загрузка истории:
// 1. Загрузить сообщения через api.getMessages(contactId)
// 2. Дешифровать каждое через client.decryptMessage()
// 3. Отобразить в MessagesArea

// Отправка:
// 1. Получить plaintext из Input
// 2. Зашифровать через client.encryptMessage()
// 3. Отправить через api.sendMessage()
// 4. Добавить в локальный список

// Polling:
// - Каждые 10 секунд проверять новые сообщения
// - Для текущего открытого контакта
// - Новые сообщения добавляются в MessagesArea
```
