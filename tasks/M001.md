# M001 — MVP (First Milestone)

## Цель

Реализовать полностью рабочий MVP foxgram: сервер, SDK и TUI-клиент, способные регистрировать пользователей, хранить зашифрованные сообщения и обмениваться ими через терминальный интерфейс.

## Scope (из AGENTS.md, фаза 1)

- [x] Регистрация / вход (с проверкой ключа)
- [x] Генерация ключей на клиенте (foxgram-core)
- [x] Ввод ключа вручную при регистрации/входе
- [x] Добавление/удаление контактов
- [x] Отправка зашифрованных сообщений
- [x] Получение сообщений (polling каждые N секунд)
- [x] Просмотр истории переписки
- [x] TUI интерфейс (список чатов, окно сообщений, добавление/удаление контактов)

## Не входит в M001

- Поиск пользователей по username
- Подтверждение ключей (key fingerprint verification)
- Групповые чаты
- Передача файлов
- Уведомления (desktop notifications)
- Экспорт/импорт ключей (QR код)

---

## Зависимости между модулями

```
cli ──► foxgram-core ──► backend (API)
```

Порядок реализации:
1. **foxgram-core** — SDK без зависимостей от других модулей (кроме libsodium)
2. **backend** — сервер, не зависит от SDK
3. **cli** — зависит и от SDK, и от сервера

## Критерии приёмки M001

1. `npm start` в backend запускает сервер на порту 3000
2. Пользователь может зарегистрироваться и войти через CLI
3. Можно добавить контакт (username + publicKey)
4. Можно отправить зашифрованное сообщение другому пользователю
5. Получатель видит сообщение в TUI (polling)
6. История переписки отображается в чате
7. Все ключи хранятся локально, сервер не видит plaintext
