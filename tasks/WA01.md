# WA01 — Web: LoginPage

## Модуль
`packages/web`

## Описание
Реализовать страницу логина с полями username/password, мутацией login и редиректом на `/chat`.

## Контекст
- Документация: `docs/web.md` разделы 4, 14
- Зависит от: WC04 (authStore), WS01 (socketStore)

## Задачи

### 1. Создать `src/pages/LoginPage.tsx`
- [ ] Поля: `username`, `password`
- [ ] Валидация: оба поля обязательны
- [ ] Состояние загрузки (spinner на кнопке)
- [ ] Ошибки от сервера отображаются под формой

### 2. Создать `src/queries/auth/useLoginMutation.ts`
- [ ] `useMutation` для `POST /api/auth/login`
- [ ] После успеха: вызвать `authStore.setAuth({ userId, username, publicKey })`
- [ ] После успеха: вызвать `socketStore.connect()`

### 3. Создать `src/hooks/useAuth.ts`
- [ ] Оркестрирует `useLoginMutation` + `authStore`
- [ ] Экспортирует `login(username, password)` функцию

### 4. Роут `/login`
- [ ] Guard: редирект на `/chat` если аутентифицирован
- [ ] Ссылка на `/register` внизу

## Результат
- Логин работает, токен из куки
- После логина — редирект на `/chat`
- Socket.io подключается автоматически
- `npm run build` проходит

## Зависимости
WC04, WS01.
