# CL001 — cli: Setup project, config, and entry point

## Модуль
`packages/cli`

## Описание
Создать структуру проекта CLI с нуля: package.json, tsconfig, базовая настройка.

## Контекст
- Документация: `docs/cli.md`
- Зависит от: foxgram-core (локальный пакет)

## Задачи

### 1.1 Инициализация проекта
- [ ] Создать `packages/cli/package.json`
  - name: `foxgram-cli`
  - bin: `foxgram: ./dist/index.js`
  - scripts: `start: ts-node src/index.ts`, `build: tsc`
  - dependencies: `foxgram-core ^1.0.0`, `ink ^4.0.0`, `react ^18.0.0`, `yargs ^17.0.0`, `chalk ^5.0.0`
  - devDependencies: `typescript ^5.0.0`, `@types/react ^18.0.0`, `@types/node ^20.0.0`, `@types/yargs ^17.0.0`, `ts-node ^10.9.0`
- [ ] Создать `packages/cli/tsconfig.json`
  - target: ES2020, module: commonjs, outDir: `dist`, rootDir: `src`
  - declaration: true, sourceMap: true, strict: true
  - jsx: react-jsx
- [ ] Создать `packages/cli/README.md`

### 1.2 Создать `src/config.ts`
