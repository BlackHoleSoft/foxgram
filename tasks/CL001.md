# CL001 — cli: Инициализация проекта и инфраструктурные модули

## Модуль
`packages/cli`

## Описание
Создать проект CLI с нуля: package.json, tsconfig, вспомогательные модули (renderer, prompt, state) и точку входа с главным циклом. Все экраны на этом этапе — заглушки.

## Контекст
- Документация: `docs/cli.md`
- foxgram-core: CommonJS, `packages/foxgram-core/dist/index.js`
- chalk@4 (не v5) — CJS-совместимый

## Задачи

{

### 1.3 Создать `src/renderer.ts`

Функции для вывода в терминал через `chalk` и `console.log`:

```typescript
import chalk from 'chalk';
import { DecryptedMessage } from 'foxgram-core';

export function printHeader(title: string): void
// Выводит рамку: ╔══════╗ ║ title ║ ╚══════╝

export function printSection(title: string): void
// Выводит: ── title ─────────────

export function printMenu(items: { key: string; label: string }[]): void
// Для каждого item: "  key. label"

export function printError(msg: string): void
// chalk.red(msg)

export function printSuccess(msg: string): void
// chalk.green(msg)

export function printSeparator(): void
// Пустая строка-разделитель

export function printMessage(msg: DecryptedMessage, myUserId: string): void
// Формат: [HH:MM] username: content
// Исходящие (msg.senderId === myUserId): chalk.cyan
// Входящие: chalk.white
// formatTimestamp: new Date(msg.timestamp) → [HH:MM]
```

### 1.4 Создать `src/prompt.ts`

Обёртки над Node.js `readline`. Создать один `readline.Interface` на весь процесс.

```typescript
import * as readline from 'readline';

export function closePrompt(): void
// Закрыть readline interface

export async function ask(label: string): Promise<string>
// Вывести "label: " и вернуть ввод пользователя

export async function password(label: string): Promise<string>
// Вывести "label: " (без echo), вернуть ввод
// Реализовать через mute/unmute с process.stdout.write

export async function choose(label: string, max: number): Promise<number>
// Вывести "label (0-max): ", принять и валидировать число в диапазоне [0, max]
// При невалидном вводе повторять запрос

export async function confirm(label: string): Promise<boolean>
// Вывести "label (y/N): ", вернуть true если ввод "y" или "Y"
```

### 1.6 Создать заглушки экранов

Создать файлы, которые реализуются в CL002–CL005.
Каждый экспортирует асинхронную функцию с подписью `(state: AppState) => Promise<Screen>` и просто возвращает `'exit'`.

### 1.7 Создать `src/index.ts` — точка входа

```typescript
#!/usr/bin/env node

import { Foxgram } from 'foxgram-core';
import { AppState, Screen } from './state';
import { authMenu } from './screens/auth-menu';
import { contactList } from './screens/contact-list';
import { addContact } from './screens/add-contact';
import { deleteContacts } from './screens/delete-contacts';
import { chat } from './screens/chat';
import { closePrompt } from './prompt';

async function main(): Promise<void> {
  const serverUrl = process.env.FOXGRAM_SERVER ?? 'http://localhost:3000';
  const foxgram = new Foxgram({ serverUrl });

  const state: AppState = { foxgram, selectedContact: null };
  let screen: Screen = 'auth-menu';

  while (screen !== 'exit') {
    switch (screen) {
      case 'auth-menu':    screen = await authMenu(state); break;
      case 'contact-list': screen = await contactList(state); break;
      case 'add-contact':  screen = await addContact(state); break;
      case 'delete-contacts': screen = await deleteContacts(state); break;
      case 'chat':         screen = await chat(state); break;
      default:             screen = 'exit';
    }
  }

  closePrompt();
}

main().catch((err: Error) => {
  console.error(err.message);
  process.exit(1);
});
```
