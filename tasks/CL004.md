# CL004 — cli: Contact list screen (main screen)

## Модуль
`packages/cli`

## Описание
Реализовать главный экран — список контактов с навигацией.

## Контекст
- Документация: `docs/cli.md` (секция Contact List)
- Зависит от: CL001-CL003

## Задачи

### 4.1 Создать `src/screens/contact-list.ts`

Терминальный экран:
```
┌─────────────────────────────────┐
│  FOXGRAM — alice           [⚙] │
├─────────────────────────────────┤
│                                 │
│  Contacts                       │
│                                 │
│  ┌─────────────────────────┐    │
│  │ ○ bob                   │    │
│  │ ○ charlie               │    │
│  │ ○ dave                  │    │
│  └─────────────────────────┘    │
│                                 │
│  [ Chat ]  [ + Add ]  [ ✕ Del ]│
│                                 │
│         [ Logout ]              │
└─────────────────────────────────┘
```

### 4.2 Реализовать компоненты

```typescript
// ContactListScreen — основной компонент
// - Отображает список контактов
// - Выделение выбранного контакта
// - Кнопки: Chat, Add, Delete, Logout

// ContactItem — элемент списка
// - Radio button (○ / ●)
// - Имя контакта
// - Выделение при наведении

// ContactButton — кнопка
// - [ Chat ], [ + Add ], [ ✕ Del ], [ Logout ]
// - Hover эффект
// - onClick обработчик
```

### 4.3 Состояние экрана
- Загружать контакты из storage (foxgram-core)
- Выделенный контакт: selectedContactId
- Текущий пользователь: из config

### 4.4 Навигация
- Chat → открыть чат с выбранным контактом
- Add → экран добавления контакта
- Delete → экран удаления контактов
- Logout → выйти на экран входа

### 4.5 Обновить `src/screens/index.ts`
```typescript
export * from './contact-list';
```

## Результат
- `src/screens/contact-list.ts` — главный экран
- Список контактов отображается
- Выделение и навигация работают
- Кнопки вызывают нужные действия

## Зависимости
- CL001, CL002, CL003
