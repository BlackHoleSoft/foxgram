# CL004 — cli: Экраны добавления и удаления контактов

## Модуль
`packages/cli`

## Описание
Реализовать два экрана управления контактами: добавление нового контакта и удаление существующих. Данные сохраняются через foxgram-core в contacts.json.

## Контекст
- Документация: `docs/cli.md` (секции Add Contact, Delete Contacts)
- Зависит от: CL001–CL003
- `foxgram.addContact(contact: Contact)` — сохраняет в contacts.json
- `foxgram.removeContact(userId: string)` — удаляет из contacts.json
- `foxgram.getContacts()` → `Contact[]`
- `Contact: { userId: string, username: string, publicKey: string }`
- userId — UUID, который пользователи обменивают вручную вместе с publicKey
