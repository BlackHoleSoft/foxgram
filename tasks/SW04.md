# SW04 — Backend: push-подписки и отправка уведомлений

## Модуль
`packages/backend`

## Описание
Реализовать REST-эндпоинты для push-подписок и логику отправки push при новом сообщении.

## Контекст
- Документация: `docs/web.md` разделы 8.3 и 8.5
- Зависит от: SW03 (таблица + VAPID)

## Задачи

### 1. `POST /api/push/subscribe` (protected)
- [ ] Тело: `{ subscription: PushSubscription }`
- [ ] Сохранить подписку в `push_subscriptions`
- [ ] endpoint → unique constraint (если дубликат — обновить)

### 2. `DELETE /api/push/subscribe` (protected)
- [ ] Удалить подписку текущего пользователя

### 3. Push при новом сообщении
- [ ] В route `POST /api/messages/send` после сохранения:
  - Если получатель online (есть socket) → `message:new` через socket.io
  - Если offline → найти подписки в БД → отправить Web Push
- [ ] Payload пуша: `{ title, body, icon, data: { contactId } }`
- [ ] Тело пуша НЕ содержит текст сообщения (E2E приватность)

## Результат
- Клиент может подписаться/отписаться от push
- Offline-пользователи получают push-уведомления
- Текст сообщения не утекает в push

## Зависимости
SW03.
