# C002 — foxgram-core: Crypto module

## Модуль
`packages/foxgram-core`

## Описание
Реализовать криптографический модуль: генерация ключей, шифрование/дешифровка сообщений с использованием libsodium-wrappers.

## Контекст
- Документация: `docs/foxgram-core.md` (секция Crypto Module)
- Документация: `docs/encryption.md` (полная спецификация)
- Зависит от: `libsodium-wrappers`

## Задачи

### 2.1 Создать `src/crypto/keypair.ts`

```typescript
// generateKeyPair(): KeyPair
// - Генерирует X25519 ключевую пару через sodium.crypto_box_keypair()
// - Возвращает { publicKey, secretKey } как base64url строки
// - Инициализирует libsodium если нужно

// getPublicKey(secretKey: string): string
// - Вычисляет публичный ключ из секретного
// - Использует sodium.crypto_box_publickey_from_secretkey()
// - Возвращает base64url строку

// importSecretKey(secretKey: string): string
// - Импортирует секретный ключ из base64url
// - Валидирует длину (32 байта)
// - Возвращает внутренний ключ libsodium
```

### 2.2 Создать `src/crypto/message.ts`

```typescript
// encryptMessage(params): { encryptedContent: string, nonce: string }
// - params: { message: string, mySecretKey: string, theirPublicKey: string }
// - Вычисляет sharedSecret = X2519(mySecretKey, theirPublicKey)
// - Генерирует случайный nonce (24 байта)
// - Шифрует: XChaCha20-Poly1305(sharedSecret, nonce, message)
// - encryptedContent = base64url(nonce || ciphertext)
// - Возвращает { encryptedContent, nonce }

// decryptMessage(params): string
// - params: { encryptedContent: string, mySecretKey: string, theirPublicKey: string }
// - Извлекает nonce (первые 24 байта) из encryptedContent
// - Вычисляет sharedSecret = X25519(mySecretKey, theirPublicKey)
// - Дешифрует: XChaCha20-Poly1305(sharedSecret, nonce, ciphertext)
// - Возвращает plaintext строку
```

### 2.3 Создать `src/crypto/index.ts`
Экспортировать все функции из keypair.ts и message.ts.

### 2.4 Валидация входных данных
- Проверка длины ключей (32 байта / 44 символа base64url)
- Проверка формата base64url
- Бросок понятных ошибок при невалидных данных

## Результат
- `src/crypto/keypair.ts` — функции работы с ключами
- `src/crypto/message.ts` — шифрование/дешифровка
- `src/crypto/index.ts` — экспорты
- Все функции работают корректно
