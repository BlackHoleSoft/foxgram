# CL002 — cli: Экраны авторизации (auth-menu, login, register)

## Модуль
`packages/cli`

## Описание
Реализовать три экрана авторизации: меню выбора, вход и регистрация. После этой задачи пользователь может зарегистрироваться или войти, после чего переходит на экран списка контактов (заглушка из CL001).

## Контекст
- Документация: `docs/cli.md` (секции Auth Menu, Login, Register)
- Зависит от: CL001
- `foxgram.register(username, password, secretKey?)` → `AuthResult { token, userId }`
- `foxgram.login(username, password)` → `AuthResult` (требует наличия secretKey в config.json — то есть пользователь должен был ранее зарегистрироваться на этой машине)
- `foxgram.logout()` → очищает config.json и contacts.json

## Задачи

### 2.1 Реализовать `src/screens/auth-menu.ts`

Вывод:
```
╔══════════════════════════╗
║         FOXGRAM          ║
╚══════════════════════════╝
Server: http://localhost:3000

  1. Login
  2. Register
  0. Exit
```

Логика:
- Использовать `printHeader`, `printMenu` из renderer.ts
- Прочитать serverUrl из `process.env.FOXGRAM_SERVER ?? 'http://localhost:3000'` и вывести под заголовком
- `choose('Select', 2)` → 1 → вернуть результат `login(state)`, 2 → `register(state)`, 0 → `'exit'`
- auth-menu не возвращает Screen напрямую — он вызывает login/register и возвращает их результат

## Результат
- `src/screens/auth-menu.ts` — меню авторизации
- `src/screens/login.ts` — экран входа
- `src/screens/register.ts` — экран регистрации

- После регистрации/входа — выводит приветствие и переходит на contact-list (заглушка, завершает процесс)
