# WC03 — Web: стили и тема (Tailwind + dark mode)

## Модуль
`packages/web`

## Описание
Настроить Tailwind CSS v4 с light/dark темами, шрифтами и базовыми стилями для компонентов.

## Контекст
- Документация: `docs/web.md` раздел 5 (UI-концепция)
- Зависит от: WC01 (Tailwind уже установлен)

## Задачи

### 1. Настроить CSS-переменные темы
- [ ] `--background`, `--foreground` (light/dark)
- [ ] `--primary`, `--primary-foreground` (indigo/violet)
- [ ] `--muted`, `--muted-foreground`
- [ ] `--border`, `--ring`
- [ ] `--card`, `--card-foreground`
- [ ] `--popover`, `--popover-foreground`

### 2. Настроить dark mode
- [ ] `@media (prefers-color-scheme: dark)` для автоматического переключения
- [ ] Ручной переключатель через CSS-класс `dark` на `<html>`
- [ ] `prefers-color-scheme` как default, переопределение через `localStorage`

### 3. Базовые стили
- [ ] Сброс стилей (reset)
- [ ] Шрифт: системный стек (Inter или system-ui)
- [ ] Глобальные стили для layout (Telegram-like, десктоп)
- [ ] Стили для MessageBubble (исходящие справа, входящие слева)
- [ ] Стили для ContactList (левая панель)

## Результат
- Light и dark темы работают
- `prefers-color-scheme` определяется автоматически
- Переключатель темы сохраняет выбор в `localStorage`
- Базовые компоненты стилизованы

## Зависимости
WC01.
