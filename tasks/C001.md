# C001 — foxgram-core: Setup project, types, and public API

## Модуль
`packages/foxgram-core`

## Описание
Создать структуру проекта foxgram-core с нуля: package.json, tsconfig.json, базовая директория, и публичный API с интерфейсами.

## Контекст
- Документация: `docs/foxgram-core.md`
- Зависимость: только `libsodium-wrappers`
- Этот модуль не зависит от backend и cli

## Задачи

### 1.1 Инициализация проекта
- [ ] Создать `packages/foxgram-core/package.json`
  - name: `foxgram-core`
  - main: `dist/index.js`
  - types: `dist/index.d.ts`
  - dependencies: `libsodium-wrappers ^0.7.0`
  - devDependencies: `typescript ^5.0.0`, `@types/node ^20.0.0`
- [ ] Создать `packages/foxgram-core/tsconfig.json`
  - target: ES2020, module: commonjs, outDir: `dist`, rootDir: `src`
  - declaration: true, declarationMap: true
  - sourceMap: true
  - strict: true
- [ ] Создать директорию `packages/foxgram-core/src/`
- [ ] Добавить `README.md` с кратким описанием

### 1.2 Определить типы (`src/types.ts`)
Создать `src/types.ts` со всеми интерфейсами из документации:

```typescript
// Configuration
export interface FoxgramConfig {
  serverUrl: string;
  homeDir?: string;
}

// Key pair
export interface KeyPair {
  publicKey: string;  // base64url, 32 bytes
  secretKey: string;  // base64url, 32 bytes
}

// Contact
export interface Contact {
  userId: string;
  username: string;
  publicKey: string;  // base64url
}

// Message (stored format)
export interface StoredMessage {
  id: string;
  senderId: string;
  encryptedContent: string;  // base64url, contains nonce || ciphertext
  timestamp: number;
}

// Decrypted message (for UI)
export interface DecryptedMessage {
  id: string;
  senderId: string;
  senderUsername: string;
  content: string;  // plaintext
  timestamp: number;
  isOutgoing: boolean;
}

// Send message result
export interface SendMessageResult {
  messageId: string;
  timestamp: number;
}

// Auth result
export interface AuthResult {
  token: string;
  userId: string;
}

// API errors
export interface ApiError {
  code: string;
  message: string;
}
```

### 1.3 Создать публичный API (`src/index.ts`)
Создать `src/index.ts` с экспортом `Foxgram` класса и перекрестными экспортами:

```typescript
export * from './types';
export { Foxgram } from './foxgram';
```

## Результат
- `packages/foxgram-core/` с package.json, tsconfig.json, src/
- `src/types.ts` — все типы
- `src/index.ts` — публичный API
- `npm run build` проходит без ошибок

## Зависимости
Нет. Самостоятельная задача.
