# WC02 — Web: IndexedDB слой (db.ts)

## Модуль
`packages/web`

## Описание
Создать IndexedDB обёртку на `idb` с объектными хранилищами для ключей, контактов, сообщений и аватаров.

## Контекст
- Документация: `docs/web.md` раздел 6
- Библиотека: `idb` (уже установлена в WC01)

## Задачи

### 1. Создать `src/services/db.ts`
- [ ] База `foxgram-db`, версия 1
- [ ] Объектное хранилище `keys`: `{ id, encryptedSecretKey, salt, iv, publicKey }`
- [ ] Объектное хранилище `config`: `{ userId, username, serverUrl }`
- [ ] Объектное хранилище `contacts`: `{ userId, username, publicKey }`, index по `username`
- [ ] Объектное хранилище `avatars`: `{ userId, avatar }`
- [ ] Объектное хранилище `messages`: `{ id, contactId, senderId, content, timestamp, isOutgoing }`, индексы по `contactId` и `contactId + timestamp`

> **Важно:** `push_subscriptions` **не** хранится в IndexedDB — это `localStorage` (см. docs/web.md §6). Всего **5** объектных хранилищ.

### 2. Создать обёртки
- [ ] `openDatabase(): Promise<IDBDatabase>` — lazy open
- [ ] CRUD-функции для каждого хранилища: `get`, `put`, `delete`, `getAll`, `clear`
- [ ] Типизированные интерфейсы для всех записей

## Результат
- Все 5 объектных хранилищ работают
- TypeScript типы для всех операций
- `npm run build` проходит

## Зависимости
WC01.
