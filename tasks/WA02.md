# WA02 — Web: RegisterPage

## Модуль
`packages/web`

## Описание
Реализовать страницу регистрации с генерацией keypair, шифрованием secretKey и сохранением в IndexedDB.

## Контекст
- Документация: `docs/web.md` разделы 4, 7, 14
- Зависит от: WC02 (IndexedDB), WC04 (authStore)

## Задачи

### 1. Создать `src/pages/RegisterPage.tsx`
- [ ] Поля: `username`, `password`, `confirmPassword`
- [ ] Валидация: password match, username 3-32 chars, password ≥ 8 chars
- [ ] Состояние загрузки

### 2. Создать `src/queries/auth/useRegisterMutation.ts`
- [ ] `useMutation` для `POST /api/auth/register`
- [ ] Генерация keypair: `foxgram-core.generateKeyPair()`
- [ ] Шифрование secretKey: PBKDF2(password, salt) → AES-GCM(secretKey)
- [ ] Сохранение в IndexedDB `keys`: `{ encryptedSecretKey, salt, iv, publicKey }`
- [ ] Сохранение в IndexedDB `config`: `{ userId, username, serverUrl }`

### 3. Интеграция с LoginPage
- [ ] Ссылка на `/login` внизу формы регистрации

## Результат
- Регистрация генерирует keypair, сохраняет зашифрованный secretKey в IDB
- После регистрации — редирект на `/login`
- `npm run build` проходит

## Зависимости
WC02, WC04.
