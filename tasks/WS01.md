# WS01 — Web: socket.io клиент (socket.ts)

## Модуль
`packages/web`

## Описание
Реализовать socket.io клиент с аутентификацией через куку, обработкой событий и интеграцией с socketStore.

## Контекст
- Документация: `docs/web.md` разделы 8.1, 15
- Зависит от: WC04 (socketStore)

## Задачи

### 1. Создать `src/services/socket.ts`
- [ ] `io(serverUrl, { withCredentials: true })` — кука отправляется автоматически
- [ ] `reconnection: true`, `reconnectionDelay: 1000`
- [ ] События от сервера:
  - `message:new` → запись в IndexedDB (encryptedContent)
  - `typing:start` → `chatStore.setTyping(userId, true)`
  - `typing:stop` → `chatStore.setTyping(userId, false)`
  - `user:online` → `chatStore.setOnline(userId, true)`
  - `user:offline` → `chatStore.setOnline(userId, false)`
- [ ] События на сервер:
  - `typing:start` / `typing:stop` с `toUserId`
  - `user:subscribe` с `userId`

### 2. Интегрировать с socketStore
- [ ] `connect()` — инициализация socket, подключение
- [ ] `disconnect()` — отключение
- [ ] `emitTypingStart/Stop` — обёртки

## Результат
- WebSocket-соединение устанавливается после логина
- События обрабатываются и обновляют stores
- `npm run build` проходит

## Зависимости
WC04.
