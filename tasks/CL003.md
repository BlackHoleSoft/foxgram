# CL003 — cli: Экран списка контактов

## Модуль
`packages/cli`

## Описание
Реализовать главный экран после авторизации: список контактов с навигацией. Пользователь выбирает контакт для чата по номеру, либо переходит к добавлению/удалению контактов, выходит из аккаунта или завершает программу.

## Контекст
- Документация: `docs/cli.md` (секция Contact List)
- Зависит от: CL001, CL002
- `foxgram.getContacts()` → `Contact[]` из локального contacts.json (не требует сетевого запроса)
- `foxgram.logout()` → очищает config.json и contacts.json

## Результат
- `src/screens/contact-list.ts` — список контактов с навигацией
