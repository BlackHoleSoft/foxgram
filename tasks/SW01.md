# SW01 — Backend: socket.io интеграция

## Модуль
`packages/backend`

## Описание
Добавить socket.io к существующему Express http.Server с аутентификацией через HttpOnly-куку и CORS для браузерного origin.

## Контекст
- Документация: `docs/web.md` раздел 8.1
- Текущий backend: `docs/backend.md`
- Зависит от: текущего Express сервера

## Задачи

### 1. Установить зависимости
- [ ] `npm install socket.io cookie`
- [ ] `npm install -D @types/cookie`

### 2. Создать `src/socket.ts`
- Инициализация `Server` поверх существующего `http.Server`
- CORS: `origin` из `WEB_ORIGIN` env, `credentials: true`
- Middleware аутентификации: парсинг куки `foxgram_token` → `verifyToken` → `socket.data.userId`

### 3. Подключить socket к `index.ts`
- Импортировать и инициализировать socket.io после создания server
- Настроить broadcast-события: `user:online`, `user:offline`

### 4. Добавить env переменную
- [ ] `WEB_ORIGIN=http://localhost:5173` в `.env.example`

## Результат
- socket.io запущен поверх Express
- Аутентификация через куку `foxgram_token`
- CORS настроен для браузера
- `npm start` не ломается

## Зависимости
Нет.
