# SW03 — Backend: таблица push_subscriptions и VAPID

## Модуль
`packages/backend`

## Описание
Добавить таблицу `push_subscriptions` в SQLite и настроить VAPID-ключи для Web Push.

## Контекст
- Документация: `docs/web.md` разделы 8.4 и 8.5
- Текущая схема: `packages/backend/src/db/schema.sql`
- Зависит от: нет

## Задачи

### 1. Создать таблицу `push_subscriptions`
```sql
CREATE TABLE push_subscriptions (
  id         TEXT PRIMARY KEY,
  user_id    TEXT NOT NULL REFERENCES users(id) ON DELETE CASCADE,
  endpoint   TEXT NOT NULL UNIQUE,
  p256dh     TEXT NOT NULL,
  auth       TEXT NOT NULL,
  created_at INTEGER NOT NULL DEFAULT (unixepoch())
);
CREATE INDEX push_subs_user_idx ON push_subscriptions(user_id);
```

### 2. Установить зависимости
- [ ] `npm install web-push`
- [ ] `npm install -D @types/web-push`

### 3. Настроить VAPID
- [ ] Сгенерировать VAPID ключи: `web-push generate-vapid-keys`
- [ ] Добавить в `.env`: `VAPID_PUBLIC_KEY`, `VAPID_PRIVATE_KEY`, `VAPID_EMAIL`
- [ ] Инициализировать `web-push.setVapidDetails()` при старте сервера

## Результат
- Таблица создана в SQLite
- VAPID настроен, ключи в `.env`
- Готово к сохранению подписок

## Зависимости
Нет.
