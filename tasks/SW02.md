# SW02 — Backend: Set-Cookie в POST /api/auth/login

## Модуль
`packages/backend`

## Описание
Изменить `POST /api/auth/login` для выставления JWT в HttpOnly-куке `foxgram_token` для браузерной авторизации.

## Контекст
- Документация: `docs/web.md` раздел 8.2
- Текущий endpoint: `packages/backend/src/routes/auth.ts`
- ## Задачи

### 1. Изменить `POST /api/auth/login`
- [ ] Добавить `Set-Cookie` заголовок в успешный ответ
- [ ] Формат: `foxgram_token=<jwt>; HttpOnly; SameSite=Strict; Max-Age=604800`
- [ ] `Secure` флаг только при `NODE_ENV=production`
- [ ] Сохранить текущий `{ token, userId }` в body для обратной совместимости с CLI

## Результат
- Login возвращает куку + body с token
- CLI-клиент продолжает работать через body.token
- Браузерный клиент получает куку автоматически

## Зависимости
Нет.
