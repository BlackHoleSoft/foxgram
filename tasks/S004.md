### 4.2 POST /api/auth/register

**Request:**
```json
{
  "username": "alice",
  "password": "secretpass123",
  "publicKey": "YWJjZGVmZ2hpamtsbW5vcA"
}
```

**Логика:**
1. Валидация:
   - username: `[a-zA-Z0-9_]`, 3-32 chars → 400 if invalid
   - password: min 8 chars → 400 if too short
   - publicKey: base64url, 32 bytes → 400 if invalid
2. Проверить уникальность username в БД
3. Хэшировать пароль: `argon2.hash(password)`
4. Сгенерировать UUID для userId
5. INSERT в users table
6. Сгенерировать JWT (userId, exp: 7 days)
7. Ответ 201: `{ token, userId }`

**Errors:**
- `400 { "error": "Username already taken" }`
- `400 { "error": "Invalid public key format" }`
- `400 { "error": "Password must be at least 8 characters" }`

### 4.3 POST /api/auth/login

**Request:**
```json
{
  "username": "alice",
  "password": "secretpass123"
}
```

**Логика:**
1. Найти пользователя по username
2. Если не найден → 401 `{ "error": "Invalid credentials" }`
3. Проверить пароль: `argon2.verify(passwordHash, password)`
4. Если не совпал → 401 `{ "error": "Invalid credentials" }`
5. Сгенерировать JWT (userId, exp: 7 days)
6. Ответ 200: `{ token, userId }`

**Errors:**
- `401 { "error": "Invalid credentials" }`

### 4.4 Зарегистрировать роуты в `src/index.ts`
```typescript
app.use('/api/auth', authRouter);
```

## Результат
- `src/routes/auth.ts` — маршруты register и login
- Регистрация создаёт пользователя с хэшированным паролем
- Вход верифицирует пароль и выдаёт JWT
- Валидация всех полей
- JWT истекает через 7 дней
