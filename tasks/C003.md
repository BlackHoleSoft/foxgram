# C003 — foxgram-core: API client module

## Модуль
`packages/foxgram-core`

## Описание
Реализовать HTTP-клиент для общения с backend API: регистрация, вход, отправка/получение сообщений, работа с контактами.

## Контекст
- Документация: `docs/foxgram-core.md` (секция API Module)
- Документация: `docs/api.md` (полная спецификация API)
- Зависит от: C001 (типы), C002 (crypto для шифрования перед отправкой)

### 3.2 Реализовать HTTP-запросы
- Использовать `fetch` (Node.js 18+ имеет встроенный fetch)
- Все запросы с заголовком `Authorization: Bearer <token>`
- Парсинг JSON ответов
- Обработка ошибок сети

### 3.3 Обработка ошибок API

```typescript
// Преобразовать HTTP ошибки в ApiError:
interface ApiError {
  code: string;  // 'USERNAME_TAKEN', 'INVALID_KEY', 'INVALID_CREDENTIALS', 'KEY_MISMATCH', 'RECIPIENT_NOT_FOUND', 'INVALID_MESSAGE', 'UNAUTHORIZED', 'USER_NOT_FOUND'
  message: string;
}
```

### 3.4 Создать `src/api/index.ts`
Экспорт `ApiClient`.
