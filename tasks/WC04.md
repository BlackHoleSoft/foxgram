# WC04 — Web: authStore и socketStore (Zustand)

## Модуль
`packages/web`

## Описание
Создать Zustand-хранилища для авторизации, чата и WebSocket-соединения.

## Контекст
- Документация: `docs/web.md` разделы 12, 15
- Зависит от: нет

## Задачи

### 1. `src/stores/authStore.ts`
- [ ] Интерфейс: `userId`, `username`, `publicKey`, `secretKey` (только в памяти), `isAuthenticated`
- [ ] Методы: `setAuth(data)`, `setSecretKey(key)`, `logout()`
- [ ] `secretKey` НЕ сохраняется в persist — только в памяти сессии

### 2. `src/stores/chatStore.ts`
- [ ] Интерфейс: `activeContactId`, `typingUsers: Set<string>`, `onlineUsers: Set<string>`
- [ ] Методы: `setActiveContact`, `setTyping(userId, isTyping)`, `setOnline(userId, isOnline)`

### 3. `src/stores/socketStore.ts`
- [ ] Интерфейс: `socket: Socket | null`, `connected: boolean`
- [ ] Методы: `connect()`, `disconnect()`, `emitTypingStart(toUserId)`, `emitTypingStop(toUserId)`
- [ ] `connected` — computed из `socket.connected`

## Результат
- Три хранилища работают
- TypeScript типы для всех полей
- `npm run build` проходит

## Зависимости
Нет.
