# WC01 — Web: инициализация проекта (React + Vite + shadcn/ui)

## Модуль
`packages/web`

## Описание
Создать новый пакет web с React 19, Vite 6, TypeScript и shadcn/ui.

## Контекст
- Документация: `docs/web.md` разделы 2, 3, 18
- Монорепо: workspace root `package.json`

## Задачи

### 1. Создать `packages/web/`
- [ ] `package.json` со скриптами: `dev`, `build`, `preview`
- [ ] `tsconfig.json` (strict, noUncheckedIndexedAccess)
- [ ] `vite.config.ts`
- [ ] `tailwind.config.ts`
- [ ] `index.html`

### 2. Установить зависимости
- [ ] Фреймворк: `react 19`, `react-dom`
- [ ] Роутинг: `react-router 7`
- [ ] Стейт: `zustand`
- [ ] Серверный стейт: `@tanstack/react-query`, `@tanstack/react-query-devtools`
- [ ] Стили: `tailwindcss 4`, `@tailwindcss/vite`
- [ ] UI: `class-variance-authority`, `clsx`, `tailwind-merge`
- [ ] shadcn/ui: `shadcn@latest`
- [ ] WebSocket: `socket.io-client`
- [ ] IndexedDB: `idb`
- [ ] QR: `qrcode.react`, `html5-qrcode`
- [ ] PWA: `vite-plugin-pwa`
- [ ] Dev: `@types/react`, `@types/react-dom`, `typescript`, `tailwindcss`, `@types/node`

### 3. Настроить Vite
- [ ] React plugin
- [ ] Tailwind CSS plugin
- [ ] PWA plugin (vite-plugin-pwa)
- [ ] Alias `@` → `src/`
- [ ] Proxy к backend в dev: `/api` → `http://localhost:3000`

### 4. Настроить Tailwind
- [ ] `@tailwind base`, `@tailwind components`, `@tailwind utilities`
- [ ] CSS variables для цветовой темы (light/dark)
- [ ] Indigo/violet акценты

### 5. Добавить в workspace
- [ ] Добавить `"web"` в `workspaces` root `package.json`

## Результат
- `npm run dev` запускает Vite на порту 5173
- Структура `src/` готова (assets, components, pages, hooks, queries, stores, services, sw)
- TypeScript компилируется

## Зависимости
Нет.
