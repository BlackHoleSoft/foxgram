# WP02 — Web: QR-код профиля и экспорт

## Модуль
`packages/web`

## Описание
Добавить функциональность QR-кода профиля: отображение, копирование ссылки, скачивание PNG.

## Контекст
- Документация: `docs/web.md` раздел 10 (Экспорт QR)
- Зависит от: WP01 (ProfilePage, avatar)

## Задачи

### 1. Интеграция QR в ProfilePage
- [ ] Отображение QR с собственными данными (username + userId + publicKey)
- [ ] Кнопка "Скопировать ссылку" → `foxgram://add?u=...&id=...&k=...` в буфер
- [ ] Кнопка "Сохранить QR" → скачать PNG через canvas.toDataURL()

### 2. Создать `src/components/qr/QrExport.tsx`
- [ ] Пропсы: `username: string`, `userId: string`, `publicKey: string`
- [ ] Генерирует foxgram:// URL
- [ ] Отображает QR через qrcode.react
- [ ] Кнопки копирования и скачивания

## Результат
- QR-код профиля отображается корректно
- Копирование ссылки работает
- Скачивание PNG работает
- `npm run build` проходит

WP01.
