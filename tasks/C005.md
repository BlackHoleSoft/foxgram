# C005 — foxgram-core: Main Foxgram class

## Модуль
`packages/foxgram-core`

## Описание
Собрать всё вместе в основном классе `Foxgram`, который объединяет crypto, api и storage.

## Контекст
- Документация: `docs/foxgram-core.md` (секция Public API)
- Зависит от: C001 (типы), C002 (crypto), C003 (api), C004 (storage)

## Задачи

export class Foxgram {
  private api: ApiClient;
  private storage: Storage;
  private config: FoxgramConfig;
  private currentUser: {
    userId: string;
    username: string;
    publicKey: string;
    secretKey: string;
  } | null = null;

  constructor(config: FoxgramConfig)
  // config: { serverUrl, homeDir? }

  // ---- Auth ----

  // register(username: string, password: string, secretKey?: string): Promise<AuthResult>

  // - Вызвать api.register(username, password, publicKey)
  // - Сохранить config через storage
  // - Установить currentUser

  // login(username: string, password: string): Promise<AuthResult>
  // - Загрузить сохранённый secretKey из storage

  // - Вернуть результат

  // - Вызвать api.getMessages(userId)

### 5.2 Реализовать все методы
- register: генерация ключей, вызов API, сохранение
- login: загрузка ключа, вызов API
- sendMessage: шифрование, вызов API
- getMessages: вызов API, возврат
- decryptMessage: дешифровка
- контакты: CRUD через storage
- logout: очистка
