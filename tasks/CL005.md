# CL005 — cli: Add and Delete contact screens

## Модуль
`packages/cli`

## Описание
Реализовать экраны добавления и удаления контактов.

## Контекст
- Документация: `docs/cli.md` (секции Add Contact и Delete Contacts)
- Зависит от: CL001-CL004

## Задачи

### 5.1 Создать `src/screens/add-contact.ts`

Терминальный экран:
```
┌─────────────────────────────────┐
│  ← Back        Add Contact      │
├─────────────────────────────────┤
│                                 │
│  Username: [____________]       │
│                                 │
│  Public Key:                    │
│  [________________________________] │
│                                 │
│        [ Add Contact ]          │
│                                 │
└─────────────────────────────────┘
```

Поля:
- Username (required)
- Public Key (required) — base64url, 32 bytes

Валидация:
- username: `[a-zA-Z0-9_]`, 3-32 chars
- publicKey: base64url, 32 bytes

Логика:
- Добавить контакт через storage
- Обновить список контактов
- Вернуться на contact-list

### 5.2 Создать `src/screens/delete-contacts.ts`

Терминальный экран:
```
┌─────────────────────────────────┐
│  ← Back       Delete Contacts   │
├─────────────────────────────────┤
│                                 │
│  Select contacts to delete:     │
│                                 │
│  [ ] bob                        │
│  [✓] charlie                   │
│  [ ] dave                       │
│                                 │
│       [ Delete Selected ]       │
│                                 │
└─────────────────────────────────┘
```

Элементы:
- Список контактов с чекбоксами
- Кнопка "Delete Selected"

Логика:
- Space — toggle checkbox
- Delete Selected — удалить выбранные из contacts.json
- Back — вернуться

### 5.3 Компоненты

```typescript
// Checkbox — чекбокс для удаления
// - [ ] / [✓]
// - Toggle по Space

// CheckboxItem — элемент чекбокса
// - Имя контакта
// - Выбранный/невыбранный
```

### 5.4 Обновить `src/screens/index.ts`
```typescript
export * from './add-contact';
export * from './delete-contacts';
```

## Результат
- `src/screens/add-contact.ts` — экран добавления
- `src/screens/delete-contacts.ts` — экран удаления
- Валидация полей
- Чекбоксы для удаления
- Контакты сохраняются/удаляются
