# CL005 — cli: Экран чата

## Модуль
`packages/cli`

## Описание
Реализовать экран чата: загрузка и отображение истории сообщений, отправка, опрос новых сообщений перед каждым вводом.

## Контекст
- Документация: `docs/cli.md` (секция Chat)
- Зависит от: CL001–CL004
- `foxgram.getMessages(userId)` → `StoredMessage[]`
- `foxgram.decryptMessage(msg)` → `DecryptedMessage { id, senderId, content, timestamp, isOutgoing }`
- `foxgram.sendMessage(recipientId, plaintext)` → `SendMessageResult`
- `foxgram.getUserId()` → userId текущего пользователя
- `state.selectedContact` — контакт, установленный в contact-list перед переходом сюда
