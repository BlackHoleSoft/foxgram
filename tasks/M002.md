# M002 — Foxgram Web (Milestone 002)

## Цель

Реализовать веб-версию мессенджера Foxgram: SPA на React + Vite с WebSocket-реалтаймом, IndexedDB, PWA и push-уведомлениями.

## Scope (из docs/web.md)

- [ ] Backend: socket.io интеграция
- [ ] Backend: Set-Cookie авторизация в login
- [ ] Backend: push-подписки (VAPID)
- [ ] Backend: таблица `push_subscriptions`
- [ ] Web: инициализация проекта (React + Vite + shadcn/ui)
- [ ] Web: IndexedDB слой (db.ts)
- [ ] Web: стили и тема (Tailwind + dark mode)
- [ ] Web: authStore + socketStore (Zustand)
- [ ] Web: LoginPage / RegisterPage
- [ ] Web: socket.io клиент (socket.ts)
- [ ] Web: ChatPage (левая панель + чат)
- [ ] Web: MessageBubble + ChatInput
- [ ] Web: useChat hook + useMessagesQuery
- [ ] Web: useSendMessageMutation
- [ ] Web: Typing indicator
- [ ] Web: Contacts (useContactsQuery, useAddContactMutation)
- [ ] Web: AddContactModal (QR + ссылка)
- [ ] Web: ProfilePage
- [ ] Web: Генерация аватаров
- [ ] Web: QR-код профиля
- [ ] Web: Web Push (subscribe + Service Worker)
- [ ] Web: PWA (manifest + icons + update banner)

## Не входит в M002

- Поиск пользователей по username
- Подтверждение ключей (key fingerprint verification)
- Групповые чаты
- Передача файлов
- Экспорт/импорт ключей (QR) — только сканирование

## Зависимости между модулями

```
web ──► foxgram-core ──► backend (API + socket.io)
```

Порядок реализации:
1. **backend** — socket.io, cookie auth, push (задачи SW01–SW04)
2. **web setup** — инициализация, IndexedDB, стили (задачи WC01–WC03)
3. **web core** — stores, socket client (задачи WC04–WS01)
4. **web auth** — login/register (задачи WA01–WA02)
5. **web chat** — чат, сообщения, typing (задачи WCH01–WCH04)
6. **web contacts** — контакты, аватары (задачи WCt01–WCt02)
7. **web profile** — профиль, QR (задачи WP01–WP02)
8. **web push** — push-уведомления, PWA (задачи WPU01–WPW01)

## Критерии приёмки M002

1. `npm run dev` в web запускает Vite на порту 5173
2. Пользователь может зарегистрироваться и войти через веб-интерфейс
3. WebSocket-соединение устанавливается автоматически после логина
4. Можно отправить зашифрованное сообщение другому пользователю
5. Получатель видит сообщение в реальном времени через WebSocket
6. Отображается индикатор "печатает..."
7. Онлайн-статус пользователей обновляется
8. Контакты управляются через UI (добавление/просмотр)
9. QR-код профиля генерируется и отображается
10. Push-уведомления работают при закрытой вкладке
11. Приложение устанавливается как PWA
12. Dark mode работает через переключатель и prefers-color-scheme
