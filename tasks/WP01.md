# WP01 — Web: ProfilePage

## Модуль
`packages/web`

## Описание
Реализовать страницу профиля: аватар, username, userId, QR-код, переключатель темы, кнопка выхода.

## Контекст
- Документация: `docs/web.md` разделы 4, 14
- Зависит от: WC04 (authStore)

## Задачи

### 1. Создать `src/pages/ProfilePage.tsx`
- [ ] Детерминированный pixel-art аватар (64×64px)
- [ ] Username (только чтение)
- [ ] userId с кнопкой "Копировать"
- [ ] QR-код профиля (qrcode.react)
- [ ] Кнопки: "Скопировать ссылку", "Сохранить QR"
- [ ] Переключатель темы (light/dark)
- [ ] Кнопка "Выйти" → `authStore.logout()` + `socketStore.disconnect()`

### 2. Создать `src/utils/avatar.ts`
- [ ] `generateAvatar(userId: string): string` — pixel-art на canvas
- [ ] `saveAvatar(userId, avatar): Promise<void>` — сохранение в IndexedDB
- [ ] `getAvatar(userId): Promise<string | null>` — чтение из IndexedDB
- [ ] `PALETTE` — константа 16 пастельных цветов
- [ ] `hashUserId(userId)` — djb2 hash
- [ ] `SeededRandom` — LCG PRNG
- [ ] Без внешних зависимостей

### 3. Создать `src/queries/contacts/useAvatarQuery.ts`
- [ ] `useQuery` для загрузки аватара из IndexedDB
- [ ] `queryFn`: читать из `avatars` хранилища
- [ ] Fallback: `generateAvatar(userId)` если нет в IDB

## Результат
- ProfilePage отображает аватар, QR, userId, тему
- Аватар детерминирован по userId
- Переключатель темы работает
- `npm run build` проходит

## Зависимости
WC04.
